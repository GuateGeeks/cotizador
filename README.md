# Propuesta educativa · Colegio Costa Sur

Sitio estático e interactivo de GuateGeeks para presentar a Colegio Costa Sur las modalidades INTEGRA, FLEX, EVOLUCIONA 8 y EVOLUCIONA 16, con selección de tecnología, estimación para la institución y referencias visuales de los proyectos.

## Publicar

El sitio está preparado para servirse desde la raíz de GitHub Pages. Activa Pages desde la rama `main`, carpeta `/ (root)`. La página de entrada es `index.html`.

## Archivos

- `index.html`: propuesta interactiva de Costa Sur.
- `costa-sur.css` y `costa-sur.js`: presentación y cálculos del escenario.
- `assets/`: únicamente logo e imágenes utilizadas por esta propuesta.

La plataforma Socrates Aprende abre desde su enlace público. Los importes son estimaciones comerciales y se confirman con GuateGeeks.
