# Prompts · Láminas conceptuales papercraft · R1

Registro de generación de las cinco referencias conceptuales. Los prompts documentan la intención artística; no certifican que cada detalle o cifra esté representado con exactitud en la imagen. Las fichas y los JSON de los esquemas resuelven las medidas y la construcción.

Si aparece una revisión, el PNG entregado corresponde al resultado final aprobado después de aplicarla. No se incluyen imágenes intermedias.
