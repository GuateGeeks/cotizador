# Hands Holding Things Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Characters hold their controllers, remotes and tablets believably: a new two-handed `hold` clip, upright VR
controllers, palms down in `interact`, and a resting angle per held item.

**Architecture:** Poses are authored in Blender (`scripts/blender/assets/characters.py`) with the existing world-axis
`clip()` turns. Each character's manifest gains `hand_poses`, so tests can measure grip positions and palm directions per
clip. All 12 characters are rebuilt and published once. In the app, `wearItem` places each item with an entry from a
`GRIPS` table (`web/src/world/gear.js`). The drone pilots and the Makerzoid driver play `hold`. A `hands` diagnostic
lets the browser test measure the held items.

**Tech Stack:** Blender 5.2.3 (headless, `scripts/world.py`), Python `unittest`, three.js, vitest, Playwright browser
tests.

**Spec:** `docs/superpowers/specs/2026-11-03-hands-design.md`

## Global Constraints

- Wrist angles and poses only: no finger bones, no new rigs, no Meshy, no credits.
- No change to `idle`, `walk` or `sit`, or to where any character stands.
- Every character carries every clip. The clip list becomes `['hold', 'idle', 'interact', 'sit', 'vr', 'walk']`
  (sorted).
- Bake checks stay as today: `bake_gaps` < 0.003 on the distance models and `bake_mismatch` < 0.03 on the teacher.
- Campus view stays within 150 draw calls (parity test).
- The 12 characters:
  - `char-student-pre`, `char-student-primary`, `char-student-primary-boy`, `char-student-basico`, `char-student-bach`
    and `char-teacher`
  - each of those with its `-lod1`
- **Manifests:** the Python suite rewrites manifests with CRLF, so after it run
  `git checkout -- assets/manifests docs/ASSET_CATALOG.md`. Only the publish run in Task 4 commits manifests.
- **Process:**
  - A new `runs/<name>` directory for every build or render result. Never overwrite one.
  - One heavy GPU load at a time.
  - No visual verdict until the images are opened.
- Node from `web/`: `unset -f node npm npx; export PATH=/home/adawolfs/.nvm/versions/node/v22.23.4/bin:$PATH`.
- **Dev server:** browser tests use the 4410 dev server. Verify that it serves fresh code (fetch `/@fs/<abs path>` and
  grep for a new identifier) before trusting a browser result.
- **Axes:** `hand_poses` values are in glTF axes (Y up, +Z front of the character), metres at final scale. The
  conversion from Blender is `(x, y, z) → (x, z, -y)`.

## Review Focus

1. **`sit` or `idle` changes by accident.** `sit` shares `FOREARMS`, `tap_a` and `tap_b` with `interact`. Editing those
   dicts changes how seated students type. Task 1 pins `sit` and `idle` to a baseline measured before any clip change
   (test `test_sit_and_idle_hands_match_the_baseline`).
2. **Wrist candy-wrapping.** A 90° wrist roll on a bone with no twist bone can pinch the skin. Split each roll between
   forearm and hand. Task 4 opens the `clip-hold`, `clip-vr` and `clip-interact` previews for every character.
3. **Mirrored grips.** The left and right hand frames mirror each other, so a single controller rotation can stand one
   controller upright and flip the other. `GRIPS` allows per-side entries. Task 6 measures both controllers
   (`upright` on each).
4. **Old character files without `hold`.** `clipNamed` falls back to `idle`, so a stale kit shows a pilot with arms
   down, not a crash. Task 6's growth test fails if any pilot or driver is not playing `hold` (diagnostic `clip`).
5. **Items through hands or floating off them.** An offset tuned on one character can miss on the 1.1 m and 1.75 m
   characters. Task 6 checks every holder's item for `between` and `above`, whatever the character's height.

  `idle`, `sit`, `interact`, `vr`, and `hold` once it exists. The frames are 1 and 13.
  - `grip_*` is the world position of the `vr_grip_*` empty.
  - `palm_*` is the unit palm normal.
  - Values are rounded to 4 places, in glTF axes.
- **Palm normal:** at rest (T-pose), take the hand bone's local axis (±X or ±Z) whose world direction is nearest Blender
  −Z (palms down). That axis, carried through the posed bone matrix, is the palm normal. Raise an error if the rest
  match is below 0.9.
  - If the Meshy T-pose has palms facing forward instead, ledger a ruling and use the axis nearest −Y.

  `char-student-primary` and `char-teacher` once each.

```python
def test_manifest_measures_both_hands_in_each_clip(self):
    for asset, m in self.built.items():
        for clip in ('idle', 'sit', 'interact', 'vr'):
            samples = m['hand_poses'][clip]
            self.assertEqual([s['frame'] for s in samples], [1, 13], asset)
            for s in samples:
                for side in ('l', 'r'):
                    self.assertAlmostEqual(sum(v * v for v in s[f'palm_{side}']), 1, delta=.01)

def test_sit_and_idle_hands_match_the_baseline(self):
    baseline = json.loads((ROOT / 'tests/fixtures/hand_baseline.json').read_text())
    for asset, m in self.built.items():
        for clip in ('idle', 'sit'):
            for now, then in zip(m['hand_poses'][clip], baseline[asset][clip]):
                for key in ('grip_l', 'grip_r'):
                    self.assertLess(math.dist(now[key], then[key]), .01, f'{asset} {clip} {key}')
                for key in ('palm_l', 'palm_r'):
                    self.assertGreater(sum(a * b for a, b in zip(now[key], then[key])), .99, f'{asset} {clip} {key}')
```

```python
def test_hold_brings_both_hands_together_in_front_palms_up(self):
    for asset, m in self.built.items():
        h = HEIGHTS[asset]
        for s in m['hand_poses']['hold']:
            l, r = s['grip_l'], s['grip_r']
            self.assertLess(math.dist(l, r), .15 * h, asset)                    # close together
            self.assertGreater(min(l[2], r[2]), .12 * h, asset)                  # in front of the body
            self.assertTrue(.5 * h < (l[1] + r[1]) / 2 < .75 * h, asset)         # waist to chest
            self.assertGreater(min(s['palm_l'][1], s['palm_r'][1]), .7, asset)   # palms up
```
